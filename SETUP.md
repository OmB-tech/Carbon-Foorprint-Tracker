# Carbon Footprint Tracker - Setup Guide

This document provides detailed instructions for setting up and running the Carbon Footprint Tracker project on your local machine using VS Code.

## Prerequisites

Before you begin, make sure you have the following installed on your system:

- [Node.js](https://nodejs.org/) (v16.x or newer)
- [npm](https://www.npmjs.com/) (v8.x or newer, comes with Node.js)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)

Follow these steps to get the project up and running:
